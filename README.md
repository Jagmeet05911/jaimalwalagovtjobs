# Jaimalwala Govt Jobs

Responsive Punjabi + English static website prototype.

## Files
- `index.html` — website structure
- `style.css` — responsive styling
- `app.js` — search, filters, saved jobs, language switch, and demo admin workflow
- `manifest.json` — basic web app manifest

## Publish with GitHub Pages
1. Extract this ZIP on your computer.
2. Open your repository: https://github.com/Jagmeet05911/jaimalwalagovtjobs
3. Upload the four website files (`index.html`, `style.css`, `app.js`, `manifest.json`) to the repository root, replacing the old `index.html` and `style.css` if asked.
4. Commit the changes.
5. Open repository **Settings → Pages**.
6. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
7. Wait for the published URL to appear in Settings → Pages.

## Important limitations
This is a front-end prototype. Job data and saved jobs use the visitor's own browser storage, so admin additions do not appear for other visitors. The Admin Panel is not protected by login and is not suitable for secure public administration. Before public production use, connect a secure backend/database, authentication, server-side validation, and a trusted workflow for verifying official job notices.

Never invent vacancies or deadlines. Verify each notice and application link on the recruiting body's official website before publishing.
